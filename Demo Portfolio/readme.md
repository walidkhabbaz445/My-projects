# 🌐 Personal Portfolio Website

A simple yet professional **portfolio website** built using **HTML, CSS, and JavaScript** to showcase my projects, skills, and personal brand.  
This demo was created about a year ago as an early version of my online presence and continues to serve as a base for my future portfolio redesign.

---

## 🚀 Overview

This project highlights:
- My background and technical skills
- A selection of personal and academic projects
- Contact section for collaboration or job opportunities
- Responsive layout for mobile and desktop
- Smooth animations and transitions using vanilla JavaScript

---

## 🧠 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure and content |
| **CSS3** | Styling, layout, and animations |
| **JavaScript (ES6)** | Interactivity and dynamic elements |
| **Google Fonts / Font Awesome** | Typography and icons |
| **GitHub Pages** *(optional)* | Hosting and deployment |
